# Lock-In

[English](README.en.md) | 简体中文

Lock-In 是一款面向 Windows 的本地专注辅助工具。用户可以预先设置工作时间段，并建立工作应用与工作网站白名单。在工作时段内，如果用户切换到白名单之外的应用或网站，Lock-In 会显示提醒，让用户重新确认是否继续。

Lock-In 不会强制封锁软件。它的作用是在无意识逃避发生时提供一个外部警醒信号，把下意识操作转化为有意识的选择。

> 当前项目处于产品设计与原型阶段，本文档描述的是计划实现的产品功能。

## 核心理念

- 不强制禁止应用或网站。
- 不使用娱乐时间、积分或连续打卡作为奖励。
- 不羞辱或惩罚用户。
- 用户始终保留继续使用的选择。
- 通过客观复盘帮助用户了解自己的分心模式。
- 默认只在本地保存用户的设置和行为记录。

## 工作计划

用户可以创建一个或多个工作时段，例如：

```text
开始时间：13:00
结束时间：13:40
```

工作计划支持：

- 创建单次工作时段。
- 创建按星期重复的工作时段。
- 启用、停用或删除计划。
- 为不同计划配置不同的应用和网站白名单。
- 工作时段开始后自动启用提醒。
- 工作时段结束后自动停止提醒。

## 应用白名单

用户可以将工作所需的软件加入白名单，例如：

```text
Microsoft Word
Microsoft Excel
Visual Studio Code
Notion
```

用户可以通过以下方式添加应用：

1. 从最近使用的应用中选择。
2. 浏览并选择本地程序。
3. 切换到目标窗口，让 Lock-In 自动识别并添加。

白名单中的应用在工作时段内可以正常使用，不会触发提醒。

## 网站白名单

用户可以将工作需要的网站加入白名单，例如：

```text
docs.google.com
github.com
stackoverflow.com
*.company.example
```

网站白名单按照域名判断，可以选择是否同时允许其子域名。Lock-In 不分析网页正文，也不记录用户在页面中输入的内容。

## 偏离提醒

工作时段内，如果用户切换到非白名单应用或网站，Lock-In 显示提醒：

```text
这个应用不在当前工作白名单中

当前打开：Steam
工作时段：13:00–13:40

[返回上一个窗口]  [仍然继续]
```

提醒遵循以下规则：

- 每次重新进入非白名单应用时重新提醒。
- 每次切换到非白名单网站时重新提醒。
- 用户可以返回之前的工作内容。
- 用户可以选择继续使用当前应用或网站。
- 选择继续不会受到惩罚，也不会中断当前工作计划。
- 如果持续使用达到设定时间，Lock-In 可以再次提醒。
- 切换回白名单内容后，停止本次偏离计时。

## 使用中再次提醒

用户选择继续使用非白名单内容后，Lock-In 会统计其前台使用时间。

达到设定时长后再次询问：

```text
你已经在 YouTube 停留了 5 分钟

[返回工作]  [仍然继续]
```

只有应用或网站实际位于前台时才累计时间。用户离开后暂停计时，再次进入时重新显示进入提醒。

## 晚间复盘

每天在用户设定的时间发送本地复盘通知，例如：

```text
今日工作复盘

工作时段：80 分钟
进入非白名单应用或网站：7 次
提醒后返回：5 次
选择继续：2 次
非白名单前台时间：12 分钟
```

用户打开复盘后，可以查看当天的事件记录：

```text
13:08  YouTube  选择继续，使用 5 分钟
13:20  Steam    提醒后返回
14:16  Reddit   提醒后返回
```

复盘只呈现事实，不对用户作出好坏评价。

## 功能判断规则

```text
当前是否处于工作时段？
        │
        ├── 否 → 不提醒
        │
        └── 是
             │
             ├── 当前内容在白名单中 → 不提醒
             │
             └── 当前内容不在白名单中 → 显示提醒
```

Windows 系统组件、文件资源管理器、任务管理器、密码管理器和 Lock-In 自身默认不触发提醒，用户可以管理这部分基础白名单。

## 设置

用户可以配置：

- 默认的持续使用提醒间隔。
- 晚间复盘通知时间。
- 开机时是否自动启动 Lock-In。
- 工作计划是否自动开始。
- 是否显示系统通知。
- 是否保存详细事件记录。
- 数据保留时间。

## 隐私

- 所有设置和复盘记录默认保存在本地。
- 不上传完整浏览历史。
- 网站判断只使用域名，不读取网页内容。
- 不记录键盘输入、密码、表单或页面正文。
- 用户可以随时清除全部记录。

## 第一版不包含

- 强制关闭或封锁应用。
- 防止用户退出 Lock-In。
- 读取网页正文或用户输入。
- 云端账户与跨设备同步。
- iOS 或 macOS 联动。
- 奖励、积分、排行榜或连续打卡。
- AI 判断用户是否真正工作。
- 企业级管理员控制或防绕过机制。
