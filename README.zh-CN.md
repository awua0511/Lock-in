# Lock-In

[English](README.md) | 简体中文

Lock-In 是一款面向 Windows 的本地专注辅助工具。用户可以预先设置工作时间段，并建立工作应用与工作网站白名单。在工作时段内，如果用户切换到白名单之外的应用或网站，Lock-In 会显示提醒，让用户重新确认是否继续。

Lock-In 不会强制封锁软件。它的作用是在无意识逃避发生时提供一个外部警醒信号，把下意识操作转化为有意识的选择。

> 当前已提供 M7 Windows 本机验收包，包含程序／网站提醒、持续使用提醒、每日复盘和新版界面。仍需人工验收，不是公开发布版。英文技术文档为主；本中文说明已同步主要功能和安装步骤。

## 安装与启动

### 直接试用测试包

1. 从系统托盘右键退出旧版 Lock-In。仅关闭主窗口通常只是隐藏窗口。
2. 解压完整的 Windows 测试 ZIP。
3. 双击解压后 `LockIn` 文件夹中的 `lock-in.exe`。

测试包不需要另外安装 Python。必须保留整个文件夹及 `_internal`，不能只复制 EXE。程序沿用 `%LOCALAPPDATA%\LockIn` 中的已有设置和历史，并不是独立的空白测试环境。

当前测试包由本地构建生成，并未发布到应用商店。仓库中的 `dist` 不纳入 Git；只下载仓库源码不会自动获得 EXE。具体候选包路径和验证结果见 [M7 验证报告](docs/RELEASE_VALIDATION.md)。

### 安装到当前 Windows 用户

先退出托盘程序，在解压后的 `LockIn` 文件夹中打开 PowerShell，执行：

```powershell
.\lock-in-setup.exe install
```

安装完成后，按 `Win + R`，输入 `%LOCALAPPDATA%\Programs\LockIn`，打开其中的 `Start Lock-In.cmd`。

安装不要求管理员权限，不添加开机启动任务或系统服务。当前测试包未签名；不要为了运行它而关闭 Windows 安全保护。

### 连接 Chrome / Edge

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 开启开发者模式，选择“加载已解压的扩展程序”。
3. 加载 `%LOCALAPPDATA%\Programs\LockIn\extension` 文件夹。如果文件选择器不展开环境变量，先在资源管理器打开这个路径，再复制实际完整路径。
4. 复制扩展页面显示的 ID。更换扩展路径可能改变 ID，不要直接沿用旧 ID。
5. 从托盘退出 Lock-In，在原来解压的测试包文件夹中执行注册命令：

```powershell
.\lock-in-setup.exe install --chrome-extension-id YOUR_CHROME_EXTENSION_ID
```

同时使用 Chrome 和 Edge 时：

```powershell
.\lock-in-setup.exe install --chrome-extension-id YOUR_CHROME_EXTENSION_ID --edge-extension-id YOUR_EDGE_EXTENSION_ID
```

将占位符替换成实际 ID。每个浏览器配置文件都需要加载扩展；有多个不同 ID 时，可以重复对应参数传入。不要在同一配置文件里同时启用旧路径扩展和新安装的扩展。

重新启动安装版 Lock-In，重新加载扩展，在 **Overview → Browser connection** 检查连接状态。没有连接时，网站提醒不会正常工作。只执行不带 ID 的初次安装，不会自动完成浏览器注册；后续安装会保留已配置的 ID。

### 升级、回滚和卸载

升级前退出托盘程序，从新解压的测试包再次运行 `install`，完成后重新加载浏览器扩展。

```powershell
.\lock-in-setup.exe rollback
.\lock-in-setup.exe uninstall
```

以上是两个独立操作，请按需要选择，不要连续照抄执行。回滚需要存在上一份安装，且数据库版本兼容；跨数据库版本回滚会被拒绝。卸载应从原来解压的测试包运行，不要从安装目录内部运行。

卸载保留 `%LOCALAPPDATA%\LockIn` 中的用户数据，移除属于本安装的程序和浏览器注册，并在适用时恢复之前的注册。浏览器扩展需要手动移除。不要通过删除数据库来解决升级或复盘错误。

完整验收步骤见 [M7 验收说明（英文）](MILESTONE_07.md)。Windows 10、实际多屏混合缩放、跨用户通信隔离、签名和公开分发等尚未全部完成，详见验证报告。

## 核心理念

- 不强制禁止应用或网站。
- 不使用娱乐时间、积分或连续打卡作为奖励。
- 不羞辱或惩罚用户。
- 用户始终保留继续使用的选择。
- 通过客观复盘帮助用户了解自己的分心模式。
- 默认只在本地保存用户的设置和行为记录。

## 工作计划

用户可以创建一个或多个工作时段，例如：

```text
开始时间：13:00
结束时间：13:40
```

工作计划支持：

- 创建单次工作时段。
- 创建按星期重复的工作时段。
- 启用、停用或删除计划。
- 为不同计划配置不同的应用和网站白名单。
- 工作时段开始后自动启用提醒。
- 工作时段结束后自动停止提醒。

## 应用白名单

用户可以将工作所需的软件加入白名单，例如：

```text
Microsoft Word
Microsoft Excel
Visual Studio Code
Notion
```

用户可以通过以下方式添加应用：

1. 从最近使用的应用中选择。
2. 浏览并选择本地程序。
3. 切换到目标窗口，让 Lock-In 自动识别并添加。

白名单中的应用在工作时段内可以正常使用，不会触发提醒。

## 网站白名单

用户可以将工作需要的网站加入白名单，例如：

```text
docs.google.com
github.com
stackoverflow.com
company.example
```

网站白名单按照域名判断，可以选择是否同时允许其子域名。Lock-In 不分析网页正文，也不记录用户在页面中输入的内容。

在 **Websites** 页面填写 **Domain**，通过 **Applies to** 选择所有工作时段或指定时段，按需勾选 **Include subdomains**，然后点击 **Add website**。只输入域名，不带 `https://`、路径或 `*.`；子域名通过复选框控制。

## 偏离提醒

工作时段内，如果用户切换到非白名单应用或网站，Lock-In 显示提醒：

```text
这个应用不在当前工作白名单中

当前打开：Steam
工作时段：13:00–13:40

[返回上一个窗口]  [仍然继续]
```

提醒遵循以下规则：

- 每次重新进入非白名单应用时重新提醒。
- 每次切换到非白名单网站时重新提醒。
- 程序提醒可以尝试返回之前的工作窗口，是否成功受 Windows 前台权限限制。
- 网站提醒只有 **Continue anyway**，不提供 Return。
- 点击右上角 X 或 Escape 与 Continue 相同。
- 用户可以选择继续使用当前应用或网站。
- 选择继续不会受到惩罚，也不会中断当前工作计划。
- 如果持续使用达到设定时间，Lock-In 可以再次提醒。
- 切换回白名单内容后，停止本次偏离计时。

## 使用中再次提醒

用户选择继续使用非白名单内容后，Lock-In 会统计其前台使用时间。

达到设定时长后再次询问：

```text
你已经在 YouTube 停留了 5 分钟

[仍然继续]
```

只有应用或网站实际位于前台时才累计时间。用户离开后暂停计时，再次进入时重新显示进入提醒。

## 晚间复盘

每天在用户设定的时间尝试发送一次本地复盘通知；Windows 通知设置或勿扰模式可能隐藏横幅。通知被隐藏时，仍可在 **Reviews** 页面查看记录。例如：

```text
今日工作复盘

工作时段：80 分钟
进入非白名单应用或网站：7 次
提醒后返回：5 次
选择继续：2 次
非白名单前台时间：12 分钟
```

用户打开复盘后，可以查看当天的事件记录：

```text
13:08  YouTube  选择继续，使用 5 分钟
13:20  Steam    提醒后返回
14:16  Reddit   提醒后返回
```

复盘只呈现事实，不对用户作出好坏评价。记录的工作时长仅覆盖 Lock-In 运行期间观测到的工作时段，不等于计划时长或实际生产力。重叠计划只计一次；无法确认的网站不计为白名单外使用。M6 之前的历史不补造缺失的本地日期和时长。

## 功能判断规则

```text
当前是否处于工作时段？
        │
        ├── 否 → 不提醒
        │
        └── 是
             │
             ├── 当前内容在白名单中 → 不提醒
             │
             └── 当前内容不在白名单中 → 显示提醒
```

Lock-In 自身、排除的系统窗口及无法可靠识别的上下文不会用猜测结果触发提醒。工作软件仍应通过程序白名单自行添加；不要假定所有密码管理器都已自动放行。

## 设置

用户可以配置：

- 默认的持续使用提醒间隔。
- 晚间复盘通知时间。
- 数据保留时间。

当前没有开机启动或自动更新设置。缩短历史保留时间需要确认，因为过期记录会被删除；选择 No 可取消保存。

## 隐私

- 所有设置和复盘记录默认保存在本地。
- 不上传完整浏览历史。
- 网站判断只使用域名，不读取网页内容。
- 不记录键盘输入、密码、表单或页面正文。
- 用户数据目录与程序安装目录分开；卸载不会删除设置和历史。

## 第一版不包含

- 强制关闭或封锁应用。
- 防止用户退出 Lock-In。
- 读取网页正文或用户输入。
- 云端账户与跨设备同步。
- iOS 或 macOS 联动。
- 奖励、积分、排行榜或连续打卡。
- AI 判断用户是否真正工作。
- 企业级管理员控制或防绕过机制。
